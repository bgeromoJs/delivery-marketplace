# Project guidance

- For API request feedback or backend error handling in the web frontend or Android seller app, read and follow [`.agents/skills/backend-api-feedback/SKILL.md`](.agents/skills/backend-api-feedback/SKILL.md).
- After any change to code, configuration, database, API, security, operations, frontend or Android behavior, read and follow [`.agents/skills/atualizar-documentacao-tecnica/SKILL.md`](.agents/skills/atualizar-documentacao-tecnica/SKILL.md) and update the affected documents under `docs/tecnica/` in the same change.
- When a task changes files in this repository or in any submodule, finish by following [`.agents/skills/commit-e-push-apos-build/SKILL.md`](.agents/skills/commit-e-push-apos-build/SKILL.md): run the build gate for the affected module and, only if it passes, commit and push to `origin`.
